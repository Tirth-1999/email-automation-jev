# LinkedIn launch post

I applied to almost 200 jobs in one day.

The next morning, I had no idea which company had replied.

Tools like Tsenta make mass applications easier, but they create a new problem: inbox chaos.

Applications, recruiter replies, assessments, information requests, interviews, offers, and rejections all look like ordinary emails.

So I built **Email Automation Jev**.

It turns Gmail into a visual job-search command center:

• Syncs new emails automatically
• Classifies them into clear Kanban lanes
• Groups related emails into applications
• Highlights replies, interviews, and offers
• Tracks confidence, corrections, and analytics
• Uses AI to review uncertain decisions and draft replies

At the center is **Jev**, which I like to describe as a classifier on steroids.

Instead of asking a general-purpose LLM to analyze every email, I use focused System One models:

**Choice** selects the category.
**Score** measures urgency and relevance.
**Noul** decides whether a reply is actually needed.

The result is faster, structured, probabilistic decisions that normal code can use immediately.

My biggest takeaway?

Not every AI product needs another chatbot. Sometimes the best AI works quietly inside the workflow, making thousands of small decisions useful.
