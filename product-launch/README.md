# Email Automation Jev — product launch film

An editable 60-second, 1920×1080 Remotion launch film using synthetic product data and the supplied product-video soundtrack.

```bash
npm install
npm run soundtrack
npm run dev
npm run render
```

Output: `out/email-automation-jev-launch-final.mp4`

The film never uses real email subjects, sender identities, API keys, or mailbox content. See `MUSIC_LICENSE.md` for soundtrack provenance.
